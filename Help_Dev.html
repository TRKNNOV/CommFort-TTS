1. Модульная архитектура проекта

Проект написан на AutoHotkey v2.0 и разделён на точку входа и 4 функциональных модуля для изоляции логики, интерфейса и системных вызовов:

Main.ahk

Точка входа. Обеспечивает #SingleInstance Force и строго последовательную сборку модулей через директивы #Include.

Part_1.ahk (Ядро и мониторинг)

Объявление супер-глобальных переменных, словарей фильтрации и смайлов, управление иконкой трея, логирование ошибок и таймер слежения за процессом CommFort.exe.

Part_2.ahk (Инициализация и профили)

Определение пола по Accounts.ini, инициализация COM-объектов SAPI.SpVoice, прогрев библиотеки libvosk.dll, загрузка настроек профиля и отправка сетевого тега голоса.

Part_3.ahk (Парсер и синтез речи)

Бинарный декодер файлов истории .cflog, извлечение сетевых тегов [url="tts:..."], маршрутизация между SAPI, Piper и Yandex Cloud, неблокирующий WAV-плеер.

Part_4.ahk (GUI и голосовой ввод)

Объектно-ориентированный менеджер интерфейса class TtsGuiManager (3 вкладки) и обработчик захвата речи с микрофона по удержанию LCtrl.

2. Блок-схема конвейера озвучивания (.cflog → TTS)

Шаг 1. Таймер ParseBinaryLog() (каждые 500 мс): открывает <Канал>.cflog в режиме совместного чтения (r-d) и считывает новые байты со смещения lastPos.
↓
Шаг 2. Разбор бинарных блоков (маркер 0xBC / 188): определяет тип события: 110 — текстовое сообщение, 111 — отправка картинки, 112 / 115 — системное событие.
↓
Шаг 3. Фильтрация и сетевой тег: проверка IgnoreList и SkipMyMessages → вызов ExtractAndSaveSharedVoice() (сохраняет [Shared_Ник] при обнаружении [url="tts:..."]) → фильтрация мата и замена смайлов.
↓
Шаг 4. Каскад приоритетов выбора голоса:
1) [Custom_Ник] — ручная настройка слушателя (высший приоритет);
2) [Shared_Ник] — голос, переданный самим отправителем через чат;
3) Автоподбор — по полу (IsUserFemale) и детерминированному хешу никнейма.
↓
Шаг 5. Синтез речи: маршрутизация в SAPI.SpVoice (с SSML-обработкой для Деда Вани), консольный piper.exe или REST API Yandex SpeechKit.

3. Блок-схема конвейера голосового ввода (Push-to-Talk)

Шаг 1. Перехват ~LCtrl: проверка флага !isVoiceRecBusy и выдержка паузы 250 мс (отсекает быстрые комбинации Ctrl+C / Ctrl+V).
↓
Шаг 2. Выбор движка (Автовыбор): проверка наличия vosk\libvosk.dll и папки vosk\model\. Если найдены — локальный Vosk, иначе — системная диктовка Windows (Win+H).
↓
Шаг 3. Захват аудио (Windows MCI): сигнал 850 Гц → запись через winmm\mciSendStringW напрямую в формат PCM 16 000 Гц, 16 бит, моно до отпускания LCtrl → сигнал 550 Гц.
↓
Шаг 4. Распознавание и отправка: передача PCM-буфера (после 44-байтного заголовка WAV) в vosk_recognizer_accept_waveform → парсинг JSON → заглавная первая буква → безопасная вставка через ClipboardAll() и отправка по Enter.

4. Справочник функций по модулям

Модуль Функция / Метод Назначение и логика работы
Part_1.ahk WatchCommFortProcess() Таймер (2000 мс). Отслеживает процесс CommFort.exe, определяет активный профиль из ViewerSettings.ini и запускает или перезагружает движок при смене аккаунта.
Part_1.ahk TrayClickCallback() / SetTrayIconState() Переключает глобальный флаг тишины isMuted по левому клику в трее и меняет системную иконку (shell32.dll).
Part_1.ahk LogError(context, err) Записывает исключения в tts_errors.log с автоматической ротацией при превышении размера 1 МБ.
Part_2.ahk InitSpeechEngine() Создаёт COM-объекты SAPI.SpVoice, синхронизирует позицию чтения лога, озвучивает приветствие Деда Вани, отправляет сетевой тег голоса и прогревает InitVoskEngine().
Part_2.ahk InitVoskEngine() Однократно загружает libvosk.dll и модель распознавания речи в оперативную память для мгновенного отклика при нажатии рации.
Part_2.ahk SendMySharedVoiceTag() Формирует BB-ссылку [url="tts:Ключ|Скорость"]Приветствие[/url] и отправляет её в активный канал при входе в чат.
Part_3.ahk ParseBinaryLog() Читает бинарные блоки (маркер 188) из .cflog, разбирает UTF-16 строки сообщений и управляет очередью озвучивания.
Part_3.ahk SpeakByVoiceId() Единый маршрутизатор синтеза речи: распределяет вызовы между SAPI, SpeakLocalAi() (Piper) и SpeakCloudAi() (Yandex), применяет SSML-бас для Деда Вани.
Part_3.ahk ExtractAndSaveSharedVoice() / ResolveSharedVoiceId() Извлекает скрытый тег голоса из входящих сообщений, сохраняет его в секцию [Shared_Ник] и сопоставляет с локально установленными голосами слушателя.
Part_3.ahk IsUserFemale() Определяет пол пользователя по байту из лога, значку из Accounts.ini, словарю мужских имён на «-а/-я» и окончанию никнейма.
Part_4.ahk TtsGuiManager Статический класс управления окном настроек (вкладки «Основные», «Персональные голоса», «О программе»), модальными окнами ИИ и предпрослушиванием.
Part_4.ahk HandleVoiceInputSession() Обработчик голосового ввода по удержанию LCtrl: записывает PCM 16 кГц через winmm.dll, распознаёт через Vosk (или Win+H) и отправляет текст в чат.

5. Глобальные переменные и структура tts_settings.ini

Переменная / Секция INI Тип Описание
ActiveProfile / ActiveProfileGender String / Int Текущий логин пользователя в CommFort и код его пола из Accounts.ini.
TtsMode Int (1..3) Активный режим синтеза: 1 — SAPI, 2 — Локальный ИИ (Piper), 3 — Облачный ИИ (Yandex).
VoiceInputMode Int (0/1) Флаг активности голосового ввода по удержанию клавиши Левый Ctrl.
voskModelPtr / voskDllLoaded Ptr / Bool Указатель на загруженную в память модель Vosk и флаг готовности библиотеки libvosk.dll.
[<ActiveProfile>] (INI) Секция INI Индивидуальные настройки профиля: канал, голос диктора, громкость, скорость, игнор-лист и ключи ИИ.
[Custom_<Ник>] (INI) Секция INI Персональные настройки голоса, громкости и скорости, назначенные слушателем для конкретного собеседника.
[Shared_<Ник>] (INI) Секция INI Сетевой профиль голоса (VoiceKey, Rate), автоматически полученный от собеседника из чата.
[MySharedVoice_<Профиль>] (INI) Секция INI Собственный сетевой голос пользователя, который передаётся в чат при входе.

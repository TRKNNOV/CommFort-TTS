Автономный голосовой интерфейс для клиента чата **CommFort**, написанный на **AutoHotkey v2.0**. Обеспечивает озвучивание сообщений в реальном времени с учётом пола и ролей, децентрализованный обмен голосами между участниками и мгновенный офлайн-голосовой ввод сообщений без клавиатуры.

> 💡 *Проект изначально создавался для уютного локального чата и удобства слабовидящих пользователей, не требует установки серверных плагинов и не нагружает сервер.*

---

## ✨ Ключевые возможности

* **🔊 Три движка синтеза речи (TTS) на выбор:**
  * **Стандартный SAPI** — использует голоса, установленные в Windows (`RHVoice`, `Vocalizer`, `Microsoft Irina/Pavel`). Работает без интернета и дополнительных настроек.
  * **Локальный ИИ (Piper)** — современные нейросетевые голоса высокого качества, работающие полностью офлайн.
  * **Облачный ИИ (Yandex SpeechKit)** — синтез речи через API Яндекс Облака.
* **🧠 Умное определение пола и персональный микшер:**
  * Автоматически определяет пол собеседника по базе `Accounts.ini`, бинарным логам `.cflog` и словарю имён.
  * Позволяет назначить любому участнику свой голос, громкость и скорость речи.
* **🌐 Децентрализованный обмен голосами («Мой голос для других»):**
  * Выберите голос и скорость, которыми вас будут слышать в чате — при входе скрипт отправит скрытую BB-метку, и остальные клиенты с модулем автоматически применят ваш голос.
* **🎤 Офлайн-голосовой ввод (режим рации по удержанию `Левого Ctrl`):**
  * Зажмите **Левый Ctrl** (дольше 0.25 сек), произнесите фразу после звукового сигнала и отпустите — встроенный движок **Vosk** распознает речь без интернета и отправит сообщение в активный канал.
  * Если папка `vosk` отсутствует, автоматически используется встроенная диктовка Windows (`Win + H`).
  * Стандартные комбинации (`Ctrl + C`, `Ctrl + V` и др.) работают в штатном режиме.
* **🌲 Атмосферная пасхалка:**
  * На вкладке *«Персональные голоса»* можно включить колоритное голосовое приветствие при входе в чат от егеря **Деда Вани**.

## 🚀 Быстрый старт (Портативная сборка)

1. Перейдите в раздел **[Releases](../../releases)** справа и скачайте архив **`CommFort_TTS.zip`**.
2. Распакуйте архив в любую удобную папку (например, `C:\CommFort_TTS\`).
3. Запустите клиент **CommFort** и войдите в свой аккаунт.
4. Запустите **`CommFort_TTS.exe`** (или исходный скрипт `Main.ahk` при наличии AutoHotkey v2.0).
5. После голосового подтверждения синхронизации в системном трее появится значок управления:
   * **Одиночный левый клик** — мгновенно включить/выключить звук озвучки.
   * **Двойной клик** (или ПКМ → *Настройки*) — открыть окно управления и встроенную справку.

```text

```

## 🛠️ Системные требования

* **ОС:** Windows 10 / Windows 11 (64-bit).
* **Клиент чата:** CommFort 5.x и выше (с включённым сохранением истории сообщений в настройках клиента).
* **Дополнительно:** Для работы режима SAPI рекомендуется бесплатный речевой пакет **RHVoice** (голоса `Aleksandr`, `Irina`, `Elena`).
